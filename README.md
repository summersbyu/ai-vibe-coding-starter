# Vibe Coding Lab 01

Build and publish your own invoice discount calculator. Start by **forking** this repository into your own GitHub account. Then open **your fork** in a Codespace, ask AI for one small improvement, check the results, commit and push your changes, and publish from `main` and `/docs` with GitHub Pages.

## Begin here

1. Read the [student handout](handouts/student-handout.md).
2. On the instructor repository, choose **Fork**. Owner must be your own username. Keep the repository name `ai-vibe-coding-starter` for the first lab.
3. Check the page now says **YOUR-USERNAME/ai-vibe-coding-starter** and shows it is forked from summersbyu.
4. On **your fork**, choose **Code > Codespaces > Create codespace on main**. Use 2 cores if offered.
5. The calculator preview starts automatically. Open **Invoice Calculator Preview** on port **8000** in the editor's Ports view if its browser tab does not open.

Do not launch a Codespace from the instructor repository before forking. Doing so does not give you your own repository for pushing and publishing.

## The files you will change

| File | Purpose |
| --- | --- |
| `docs/index.html` | Page content and input controls |
| `docs/styles.css` | Appearance and responsive layout |
| `docs/app.js` | Input validation and payment calculation |

The main AI route uses the Claude Code editor panel. A browser AI chat route is also documented. The public calculator itself calls no AI service and uses no keys or database. Do not put credentials or real financial data into any file.

## Stop and return

Open [My Codespaces](https://github.com/codespaces), find the workspace for **your fork**, and choose **Stop codespace** when finished. Resume that same workspace later. A published GitHub Pages site is hosted separately and should remain available after the Codespace stops.
