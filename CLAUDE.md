# Accounting course starter

Help a beginning student make small, understandable changes to a static invoice discount calculator.

- The public site lives only in docs/index.html, docs/styles.css, and docs/app.js.
- Keep the site plain HTML, CSS, and JavaScript. Do not add frameworks, packages, build steps, a database, APIs, credentials, or external assets.
- Preserve accessible labels, keyboard use, validation, integer-cent calculations, and relative asset paths.
- Explain which files you intend to edit before editing. Keep each request small and explain the resulting diff.
- Respect the student's review and permission choices. Do not change environment or permissions settings to avoid review.
- Do not commit, push, enable Pages, or publish on behalf of the student. The student performs those steps in the editor and GitHub.
- Do not change the dev container, tasks, handouts, README, or this instruction file unless the instructor explicitly requests that work.
- For calculations use test cases in handouts/test-cases.csv. Ask the student to independently check the page in the preview.
- Treat prompts and explanations as educational aids; the student owns verification and publication decisions.
